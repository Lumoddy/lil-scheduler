# Lil' Scheduler

This is an app created for university with [Expo](https://expo.dev) in [React Native](https://reactnative.dev/).

See the design document in Google Docs [here](https://docs.google.com/document/d/1zkUv04wk2ozidCgCSIIkHSFRS5OUoT9eqIctuyN4R5w/edit?usp=sharing).

See the design prototype in Figma [here](https://www.figma.com/design/P1BbYTpp52F5FC76qzVuGZ/Lil--Scheduler-2?node-id=1-3&t=acUAPwpWnCkkl6o8-1).

## What is the app?

Lil' Scheduler is an app made for people who struggle to organize their priorities. The app creates a schedule automatically by sorting and organizing the 'tasks' that the user specifies to the algorithm.

The organised tasks will be displayed on a calendar interface where the user can see. The user can then follow their tasks in the order that is shown, making them more productive instead of being stuck in decision paralysis.

## Run the app

1. Clone the repo with

   ```bash
   git clone https://github.com/Lumoddy/lil-scheduler.git
   ```

2. Navigate to app's directory with

   ```bash
   cd lil-scheduler
   ```

3. Install dependencies with

   ```bash
   npm install
   ```

4. Start the app with

   ```bash
   npx expo start
   ```
